Features GitLab OAuth 2.0 with dynamic client registration and PKCE, automatic token refresh with Secret Manager, and Cloud Run deployment.

Gemini Google Cloud GitLab MCP FastAPI Python Cloud Run OAuth 2.0 / PKCE BM25

Production-style full-stack backend for validating business ideas with source-backed market research. Node.js Express PostgreSQL Redis BullMQ JWT React Docker GitHub Actions OpenAI
